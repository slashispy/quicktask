# internal/middleware

Contiene middlewares HTTP que se pueden insertar en la cadena de manejo de peticiones.

## Ejemplos comunes

- Middleware de autenticación (JWT, API Key)
- Middleware de logging
- Middleware de CORS
- Middleware de recuperación ante pánico

## Ventaja

Permiten separar preocupaciones transversales del flujo principal de los handlers.
